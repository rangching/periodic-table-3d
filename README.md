# 3D 週期表

用 Three.js 製作的互動式 3D 週期表，單檔 ES module，不需要打包工具。

## 功能

- **週期表**：每個元素是一根立方柱，高度代表所選屬性（游離能、原子半徑、電負度、熔點、密度）。
- **原子**：原子核（質子與中子）、電子殼與繞行電子，最外層以金色標示。
- **樣品**：216 個原子的晶格，拖曳溫度滑桿觀察熔化。
- 支援手機直式版面。

## 執行

ES module 不能用 `file://` 開啟，需要本機伺服器：

```bash
python3 -m http.server 5173 --bind 127.0.0.1
```

然後開啟 <http://localhost:5173>。

## 操作

拖曳旋轉、滾輪縮放、點選元素；`←`／`→` 切換元素，`1`／`2`／`3` 切換檢視，`Esc` 回週期表。

## 資料說明

`data.js` 內的元素數值為教學用近似值，未逐筆對照權威資料庫，正式使用前請核對。
電子組態只按 Aufbau 順序排列，鉻、銅等例外元素不精確。
